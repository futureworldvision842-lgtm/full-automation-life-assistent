Scan the QR code with WhatsApp on your phone to link two-way trading notifications and AI commands.

🟡 Checking WhatsApp Bridge...

Generating Multi-Device QR Code...

  1. Open WhatsApp on your mobile phone.
  2. Tap Settings / Three Dots > Linked Devices.
  3. Tap Link a Device and point your camera at this QR code.
  4. The linked-device auth state is saved locally, excluded from Git, and reused after restarts. Protect it like a credential. Re-pairing is required if WhatsApp logs out/revokes the device or the session becomes invalid.

📱 Interactive WhatsApp Commands

Reply to your bot directly on WhatsApp using any of these commands:

system status — Verified broker mode, telemetry, execution lock & WhatsApp health
status — Broker-reported Balance, Equity, Drawdown & Trades
trades — Active Open Positions & Profit Locking
signal XAUUSD — Broker quote + closed multi-timeframe evidence, conditional levels, account fit and blockers
what if XAUUSD +0.5% — Sensitivity branch from a fresh broker baseline; not a forecast
YES / NO — Record your decision on the last reviewed signal; YES cannot bypass safety gates
remember <note> — Store a non-secret operator instruction with an audit receipt
memory list — Show recent operator memory
update status — Show local code version and pending reviewed-update requests
update request <change> — Queue a safe local-review request; remote code execution stays blocked
help — Display all available bot commands

End-to-end command check

From the paired owner chat, send system status. A verified reply confirms phone → bridge → dashboard → bot → phone routing. Never send passwords, account credentials, API keys, or recovery phrases.
